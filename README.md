### 原始文案草稿與單期拆解說明
原始 `docs/` 中有多份文件名稱雖標示為「種草規劃」或「內容規劃總覽」，實際內容卻是完整的逐期 FB 長文／IG 短文（僅 `P05-08_種草規劃.docx` 與 `P13-36_中長期戰略藍圖.docx` 兩份才是真正的策略大綱）。這些「掛羊頭賣狗肉」的彙總文件以 4 期為一份存放，逐期核對時容易因跨期彙總而遺漏錯誤（例如第17期標題與內文主題不符的問題即由此而生）。

現已將全部 9 份彙總完整文案（P01-04、P05-08、P09-12、P13-16、P17-20、P21-24、P25-28、P29-32、P33-36）拆解為 36 份單期檔案，並各自搬移至對應的 `episodes/<期數>/` 資料夾內，與該期的 `images/` 與 `article.json` 並列，方便日後逐期勾稽。檔案格式也已從 docx 統一轉為 `P01_完整文案.md` ~ `P36_完整文案.md`，方便直接在 git 上檢視差異與純文字比對。原始彙總 docx 版本移至 `docs/archive/` 保留歷史紀錄，不再作為維護依據；`episodes/` 底下目前不再存放任何 docx 檔案。

真正的策略／排程規劃文件也已整理：`P05-08_種草規劃.docx`（涵蓋4個獨立期數的切入點與圖卡概念）拆解為單期 `P05_種草規劃.md` ~ `P08_種草規劃.md`，搬入對應的 `episodes/<期數>/` 資料夾；`P13-36_中長期戰略藍圖.docx`（按3大階段、6個內容循環組織，非逐期切分）拆解為 6 份循環層級的 md 檔，留在 `docs/`（循環四 P13-16、循環五 P17-20、循環六 P21-24、循環七 P25-28、循環八 P29-32、循環九 P33-36），每份都附上所屬階段與階段目標作為獨立上下文；文件末尾「策略總結與下一步建議」為全書總結，附加於最後一份循環九檔案。原始 docx 一併移至 `docs/archive/`，`docs/` 目前只保留 md 格式的策略文件。

**已解決**：整理過程中發現 `P13-36_中長期戰略藍圖.docx`（現 `docs/P17-20_循環五_女性日常保養與代謝.md`）第17期原始規劃寫的是「鋅與女性護理」，與最終執行的完整文案（`episodes/17_.../article.json`、`P17_完整文案.md`，全篇皆為「鐵」）不一致。經確認以**圖卡與已執行文案為準**，第17期維持「鐵與女性護理」，並已同步修正 `docs/P17-20_循環五_女性日常保養與代謝.md` 的規劃表格內容，使策略文件與實際執行內容一致。原規劃中的「鋅」主題不再另外補期，36期主題數維持不變。

### 系統串接說明
`index.json` 包含了所有期數的中繼資料，可用於前端快速載入文章列表。每期的 `article.json` 包含完整的 FB 長文、IG 短文與相對路徑的圖片連結，可直接將內容串接至 App 或 LINE 官方帳號。`article.json` 為系統串接與勾稽的唯一結構化來源；同資料夾內的 `.md` 草稿（如有）僅為原始撰寫草稿，供人工比對參考。

## 內容創作準則與策略

1.  **潛意識影響**：內容應具備吸引力，利用「hook」策略吸引流量，產生知識型文案。
2.  **共鳴與科學自信**：融入「自主意識」與「科學我也懂」的科普概念，讓受眾產生共鳴並認為自己具備相關知識，減少對專業人士代言的依賴。
3.  **包容性溝通**：內容應避免直接提及「女性」，而是透過故事討論讓不同性別認同的受眾都能產生共鳴。同時，發文應使用「你/妳」等字詞，營造兩性平權的意象。
4.  **法規遵循**：確保內容符合相關法規（如衛福部法令），避免露骨地提及「繁衍」或「生理」等詞彙。
