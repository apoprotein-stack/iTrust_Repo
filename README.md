# Rotciv 的生活手札543 — 種草內容規劃專案

本專案為「Rotciv 的生活手札543」粉絲專頁的社群內容行銷規劃與資產庫。內容以女性營養知識科普為主軸，目標受眾為20-35歲女性、孕婦及媽媽族群。透過純科普的衛教導向與科學實用的內容策略，建立品牌信任度。

## 專案結構說明

本倉庫已進行重新整理，檔案依照「議題」與「素材類型」進行分類，方便後續取用與管理。

### 資料夾架構

*   `docs/`：存放整體內容規劃與文案總覽的 DOCX 文件。
*   `episodes/`：存放各期數的內容資產。每個議題為一個獨立的資料夾。
    *   `images/`：存放該期數的三張配套圖卡（封面引導 + 2 張內容科普卡）。
    *   `文案與規劃對應表`：每期數的圖卡與文案主題均已在 `docs/` 中的總覽文件詳細記錄，形成完整的勾稽對應。

### 36期內容規劃總覽

本系列內容共規劃 36 期，每週發布 2 次（週二、週四），採「3次科普 + 1次深度」的循環節奏。
